# 🥩 مشويات أبو حمزة | Abu Hamza Grills
> موقع فاخر ومودرن لمطعم مشويات ولحوم مصرية على الفحم البلدي بتصميم عالي الجودة وبصري بالكامل.

---

## 🎨 فلسفة التصميم (Design Philosophy)
- **الحد الأدنى من النصوص، أقصى تأثير بصري (Minimal Text, Maximum Visual Impact)**: صور مشويات شهية عالية الدقة هي بطل المشهد.
- **لوحة الألوان الملكية**: خلفيات فحمية وسوداء داكنة (`Charcoal & Jet Black`) مع لمسات من جمر الشواء الأحمر العميق (`Deep Red & Ember`) والتفاصيل الذهبية الفاخرة (`Royal Gold`).
- **المحاذاة والاتجاه**: تصميم مخصص بالكامل للغة العربية من اليمين إلى اليسار (`RTL`) بخط **Cairo** الحديث.
- **بطاقات طعام راقية**: اسم الطبق وسعره الاسترشادي فقط دون فقرات نصية طويلة ومشتتة.

---

## 🏛️ هيكل الموقع (Website Structure)

1. **الواجهة الرئيسية (HERO)**:
   - خلفية شواء كاملة الشاشة ذات دقة عالية مع تأثيرات داكنة وتوهج جمر خافت.
   - عنوان رئيسي ضخم: **مشويات أبو حمزة**
   - الشعار القصير: **طعم المشويات على أصوله 🔥**
   - زران فقط: `استعرض المنيو` | `تواصل معنا`

2. **قائمة المشويات (MENU)**:
   - تصنيفات بسيطة وواضحة (الكل | كباب وكفتة | ريش وطرب | مشاوي الدواجن | سرافيس وطواجن).
   - بطاقات طعام فاخرة بصور كبيرة تعرض اسم الطبق والسعر الاسترشادي فقط.
   - إمكانية النقر على أي طبق لعرض صورته بالحجم الكامل (Lightbox).

3. **معرض الصور (GALLERY)**:
   - شبكة صور عصرية (Modern Bento Grid) تضم صوراً فوتوغرافية احترافية جذابة للشواء على الجمر.
   - تفاعل تكبير فوري عند النقر.

4. **الموقع والعنوان (LOCATION)**:
   - العنوان الاسترشادي ومواعيد العمل.
   - خريطة تفاعلية مدمجة (Google Maps) بنمط ليلي متناسق.
   - زر تواصل مباشر وسريع.

5. **تذييل الصفحة (FOOTER)**:
   - اسم المطعم وشعاره.
   - روابط شبكات التواصل الاجتماعي (Instagram, Facebook, TikTok).
   - أرقام التواصل والخط الساخن الاسترشادي.
   - تنويه وإخلاء مسؤولية يوضح أن الموقع نموذج وتصميم تجريبي مقترح.

## 💻 التشغيل السريع (Quick Start)

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي
npm run dev

# بناء نسخة الإنتاج
npm run build
```
الموقع يعمل على: `http://localhost:3000/`
